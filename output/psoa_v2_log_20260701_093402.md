以下是详细的推理过程：

### 1. 初始状态设定
*   **人物**：第一个人（A，最前）、第二个人（B，中间）、第三个人（C，最后）。
*   **视野**：C 能看到 A 和 B；B 只能看到 A；A 看不到任何人。
*   **公共知识**：队长声明“至少有一顶红帽子”。这意味着组合“蓝-蓝-蓝”（BBB）被排除。

### 2. 逆向归纳推理

#### 第一步：分析第三个人（C）的回答
*   **C 的视角**：C 能看到 A 和 B 的帽子颜色。
*   **逻辑推导**：如果 C 看到 A 和 B 都是蓝色（即看到 BB），结合“至少有一顶红帽子”的条件，C 就能立刻确定自己是红色。
*   **事实**：C 说“不知道”。
*   **推论**：C 没有看到 A 和 B 都是蓝色。也就是说，**A 和 B 之中至少有一个人戴的是红帽子**（即排除了 AB 均为蓝色的情况）。

#### 第二步：分析第二个人（B）的回答
*   **B 的视角**：B 能看到 A 的帽子颜色，并且听到了 C 的回答。
*   **B 的知识**：B 知道“A 和 B 之中至少有一个人是红色”（来自 C 的“不知道”）。
*   **假设检验**：
    *   如果 B 看到 A 戴的是**蓝色**帽子，那么为了满足“A 和 B 至少有一个红色”，B 就能确定自己一定是**红色**。
    *   但是，B 也说“不知道”。
*   **推论**：B 无法确定自己的颜色，说明 B 没有看到 A 戴蓝色帽子。如果 B 看到 A 是蓝色，B 就会像 C 一样拥有确定性信息。既然 B 不确定，**A 一定不是蓝色**。

#### 第三步：得出结论
*   **A 的颜色**：既然 A 不是蓝色，那么 A 必然是**红色**。

### 3. 正向验证
我们代入结论进行验证，确保逻辑闭环：
*   **假设 A 是红色**：
    1.  **C 的观察**：C 看到 A 是红色。无论 B 是什么颜色，C 都无法仅凭 A 的颜色确定自己的颜色（因为只要 A 是红，队长说的话就成立了，C 可能是蓝也可能是红）。所以 C 说“不知道”。这符合题意。
    2.  **B 的观察与推理**：B 看到 A 是红色。B 知道“至少 A 或 B 有一个红”。既然 A 已经是红了，B 无论是红是蓝，都满足队长的条件。B 无法通过 A 的颜色推断出自己的颜色。所以 B 说“不知道”。这也符合题意。
    3.  **结果**：在 A 为红色的情况下，C 和 B 都会回答“不知道”，逻辑完全自洽。

*   **反证法（假如 A 是蓝色）**：
    1.  **C 的观察**：C 看到 A 是蓝色。
        *   若 C 看到 B 也是蓝色，C 会知道自己是红色（因为不能全蓝），C 会说“知道”。
        *   若 C 看到 B 是红色，C 无法确定自己，会说“不知道”。
    2.  **B 的观察**：B 看到 A 是蓝色。B 听到 C 说“不知道”。
        *   B 会想：“如果我也是蓝色，那 C 就会看到两个蓝色，C 就会知道他是红色并说出来。但 C 没说他知道，说明我没看到两个蓝色。既然我看到 A 是蓝色，那我肯定不是蓝色。”
        *   因此，如果 A 是蓝色，B 一定能推断出自己是红色，B 会说“知道”。
    3.  **矛盾**：题目中 B 说“不知道”，所以假设“A 是蓝色”不成立。
